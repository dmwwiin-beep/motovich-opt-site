Эта страница фиксирует оставшиеся шаги, чтобы не путать подготовленный исходный код с реально работающими уведомлениями или опубликованным Android-релизом.

1. Настройка уведомлений

  1. Создать Supabase-проект, выполнить все три миграции по порядку из supabase/migrations и запустить supabase/tests/manual_security_checks.sql.
  2. Настроить серверные секреты: SUPABASE_SERVICE_ROLE_KEY, VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_SUBJECT, MOTOVICH_ALLOWED_ORIGIN и случайный MOTOVICH_PUSH_CRON_SECRET. Приватные ключи не вводить в браузер.
  3. Развернуть функции coach, push-send, push-test, push-schedule и delete-account. В настройках MOTOVICH ввести URL проекта, публичный ключ и VAPID public key, создать аккаунт и включить Push.
  4. Нажать «Отправить тестовое уведомление мне». Затем настроить cron каждую минуту для push-schedule с заголовком x-motovich-cron-secret. Напоминания отправляются по задачам, у которых есть и дата, и время; время берётся из сохранённого часового пояса. После изменения задач снова нажми «Отправить локальные данные», так как синхронизация сейчас ручная. Журнал на сервере предотвращает повтор одного и того же напоминания.

2. Android и Google Play

Новый Android-релиз должен target API 36 или выше с 31 августа 2026 года. Для новых личных Play Console аккаунтов, созданных после 13 ноября 2023 года, перед production-запуском может требоваться закрытое тестирование минимум с 12 тестировщиками в течение 14 непрерывных дней.

Официальные требования: target API, закрытое тестирование, TWA / Digital Asset Links.

3. Блокер текущего размещения

Приложение размещено на https://dmwwiin-beep.github.io/motovich-opt-site/motovich-app/. Для полноэкранной Trusted Web Activity файл assetlinks.json должен быть доступен по корню origin: https://dmwwiin-beep.github.io/.well-known/assetlinks.json. В доступных репозиториях корневого сайта нет. Поэтому до создания root-сайта либо подключения собственного домена и получения реального SHA-256 сертификата подписи TWA нельзя считать проверенной.

Package ID app.motovich.productivity — только пример, его доступность нужно проверить и ID выбрать окончательно до первой публикации. Также необходимы release AAB, keystore, Data safety, content rating, контакт разработчика и реальные Android-скриншоты.

4. Политика и удаление аккаунта

Политика конфиденциальности и Удаление аккаунта и данных уже подготовлены. Перед отправкой в Play проверь контакт поддержки, реальные серверные подключения и ответы в Data safety.
