# MOTOVICH — прототип приложения

Самостоятельное веб-приложение для личной продуктивности на русском языке.

## Функции
- План дня и прогресс выполнения задач
- Создание, редактирование, удаление задач, сроки и приоритеты
- Трекер привычек с ежедневным сбросом отметок
- Таймер фокуса 25/5, 45/15 и 60/10
- Трекинг сна, настроения, активности и уровня энергии
- Локальный планировщик-помощник (не подключён к внешней нейросети)
- Локальное сохранение через localStorage
- PWA manifest и service worker для установки/кеширования оболочки

## Важно
Данные хранятся в браузере на текущем устройстве и не синхронизируются между устройствами. Нет регистрации, серверной базы данных, push-уведомлений или API-ключа AI. Не храните в прототипе чувствительную информацию.
